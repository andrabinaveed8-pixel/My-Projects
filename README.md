🚗 Toyota Car Data Analysis Project
📌 Project Overview

This project is a beginner-friendly Data Analysis Project using Python and Jupyter Notebook.
The notebook analyzes a Toyota car dataset to discover insights about:

Car prices
Mileage
Fuel types
Transmission types
Correlation between features
Most expensive and cheapest cars
Average statistics
Duplicate and missing values handling

The project is useful for beginners learning:

Python for Data Science
Pandas
NumPy
Data Cleaning
Exploratory Data Analysis (EDA)
🛠️ Technologies Used
Python 🐍
Jupyter Notebook 📓
Pandas
NumPy
Matplotlib
Seaborn
